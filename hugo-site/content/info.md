## 📊 サイト情報

### 技術仕様

- **ホスティング**: AWS S3 + CloudFront
- **静的サイト生成**: Hugo v0.149.0
- **テーマ**: Paper
- **デプロイ**: GitHub Actions
- **インフラ管理**: Terraform

### パフォーマンス

- **CDN**: CloudFront による高速配信
- **最適化**: 静的サイトによる軽量化
- **レスポンシブ**: モバイル対応デザイン

### セキュリティ

- **HTTPS**: 全通信の暗号化
- **IAM**: 最小権限によるアクセス制御
- **定期更新**: セキュリティパッチの適用
