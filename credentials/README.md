## ⚠️ セキュリティ警告

**重要**: このディレクトリ内のファイルは機密情報を含んでいます。以下の点を必ず守ってください：

- **Git 管理対象外**: `.gitignore`で除外されているため、リモートリポジトリにアップロードされません
- **ローカル管理**: 認証情報はローカル環境でのみ管理してください
- **共有禁止**: 認証情報を他の人と共有しないでください
- **定期的な更新**: セキュリティのため、定期的にアクセスキーをローテーションしてください

## 🔑 IAM ユーザー管理

### アクセスキーファイル

- **ファイル名**: `techblog-staging_accessKeys.csv`
- **内容**: IAM ユーザーの Access Key ID と Secret Access Key
- **用途**: CI/CD パイプラインでの AWS 認証

### セキュリティベストプラクティス

1. **アクセスキーのローテーション**

   - 90 日ごとに新しいアクセスキーを生成
   - 古いアクセスキーは削除

2. **最小権限の原則**

   - 必要最小限の権限のみ付与
   - 使用していない権限は削除

3. **監査ログの確認**
   - CloudTrail でアクセスログを確認
   - 異常なアクセスがないか定期的にチェック

## 🚨 緊急時の対応

### アクセスキーが漏洩した場合

1. **即座にアクセスキーを無効化**

   ```bash
   aws iam update-access-key --user-name USERNAME --access-key-id ACCESS_KEY_ID --status Inactive
   ```

2. **新しいアクセスキーを生成**

   ```bash
   aws iam create-access-key --user-name USERNAME
   ```

3. **古いアクセスキーを削除**

   ```bash
   aws iam delete-access-key --user-name USERNAME --access-key-id ACCESS_KEY_ID
   ```

4. **影響範囲の確認**
   - CloudTrail ログで不正アクセスの有無を確認
   - 必要に応じてリソースの再作成
